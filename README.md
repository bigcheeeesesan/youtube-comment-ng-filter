# YouTube コメントNGフィルター

YouTubeのコメント欄で、

- 指定したNGワードを含むコメントを非表示
- 指定した投稿者のコメントを非表示

にできる Tampermonkey 用ユーザースクリプトです。

通常動画・Shorts のコメント欄で動作します。

## 主な機能

- NGワードを登録して、そのワードを含むコメントを自動で非表示
- コメント投稿者をNGユーザーとして登録
- NGユーザーのコメントを他の動画でも自動で非表示
- NGワード一覧の確認・削除
- NGユーザー一覧の確認・解除
- 右下の小さい「NG」ボタンから設定メニューを開閉
- YouTube内で別の動画へ移動した場合や、後から読み込まれたコメントにも対応

## 必要なもの

Tampermonkey などのユーザースクリプト管理拡張機能が必要です。

- Tampermonkey
- Violentmonkey など

## インストール

1. Tampermonkey をブラウザにインストールします。
2. このリポジトリの `youtube-comment-ng-filterv4.user.js` を開きます。
3. `Raw` を開くか、コードを Tampermonkey に登録します。
4. YouTube を再読み込みします。

## 使い方

### NGワードを登録する

YouTube画面右下の小さい `NG` ボタンを押します。

メニューから

`＋ NGワード`

を選び、非表示にしたい言葉を入力します。

登録した言葉を含むコメントは自動で非表示になります。

### NGワードを削除する

右下の `NG` ボタンから

`ワード一覧`

を開きます。

削除したいNGワードの番号を入力してください。

すべて削除する場合は、

`all`

と入力します。

### 投稿者をNG登録する

各コメントの投稿者名付近に小さい `NG` ボタンが表示されます。

そのボタンを押すと、その投稿者をNGユーザーとして登録できます。

登録後は、そのユーザーが別の動画に投稿したコメントも自動で非表示になります。

### NGユーザーを解除する

右下の `NG` ボタンから

`ユーザー一覧`

を開きます。

解除したいユーザーの番号を入力してください。

全員解除する場合は、

`all`

と入力します。

## 再生中の動画の投稿者をNGにする（v4.0.3）

通常動画の再生ページでは、動画の投稿者のチャンネル名付近に
**「投稿者をNG」** ボタンが表示されます。
押して確認すると、既存のNG投稿者一覧に登録され、その投稿者の
動画・Shorts・コメントが非表示になります。

登録後はボタンが「NG登録済み」に変わります。
解除は右下の **NG → NG投稿者一覧** から行えます。
現在再生中の動画を閉じたり、再生を停止したりする機能ではありません。
動画を切り替えると、ボタンもその動画の投稿者に切り替わります。

### 以前の版から更新する場合

Tampermonkeyで今使っているスクリプトを開き、
`youtube-comment-ng-filterv4.user.js` の最新コードに置き換えて保存し、
YouTubeを再読み込みしてください。旧版と新版を同時に有効にしないでください。
保存キーは変更していないため、同じブラウザ・YouTubeのサイトデータが
残っていれば、登録済みのNGワードやNG投稿者を引き継ぎます。

## データの保存について

登録したNGワード・NGユーザーは、ブラウザの `localStorage` に保存されます。

外部サーバーへ送信する機能はありません。

そのため、別のブラウザや別のPCへ自動で同期されるものではありません。

ブラウザのサイトデータを削除した場合、登録内容も削除される可能性があります。

## 初期状態について

この公開版には、あらかじめ登録されたNGワードやNGユーザーはありません。

導入後、自分で必要なものを登録して使用してください。

## 注意

YouTube側の仕様変更によって動作しなくなる場合があります。

また、このスクリプトはコメントをYouTube上から削除するものではありません。

自分のブラウザ上で対象コメントを非表示にするだけです。
